# A股板块恐贪情绪指数 · SENTI-1

> 一句话：**它是一个「板块情绪温度计」，不是一个「买卖信号发生器」。**
>
> 给 6 个 A 股板块各算一条 0~100 的情绪分值：<0 表示恐慌溢出（底部区），
> >100 表示贪婪溢出（顶部区）。溢出不是人为拍的阈值，是按板块自身历史分位锚定后的自然溢出。

- 项目目录：`D:\情绪指标4`（第 4 版；前 3 版在 `D:\情绪指标`、`情绪指标2`、`情绪指标3`）
- 仓库：<https://github.com/1740611029/sentiment-index-v4>
- 深度技术文档：**[`DELIVERY.md`](DELIVERY.md)**（公式、参数、每个数字的样本量与出处、已知边界、被否决方案）

## 1. 它能做什么

| 能力 | 说明 |
|---|---|
| **情绪温度计** | 6 个板块各自的每日情绪分值（0~100 正常区间，可溢出到 −30 / +140） |
| **底部信号** | 「昨日分值 ≤ 0 且今日回升」→ 今日收盘买入，规则实时可执行、无未来函数 |
| **置信等级 A/B/C** | 每个底部信号会按两个确认层（估值投降、全场共振）打上等级，直接画在折线图上 |
| **顶部** | **已移除**（2026-09-22）。实测 2/9 = 22%，随机基线 40%，p=0.93，与瞎猜无差异 |
| **时间范围切换** | 折线图支持近 7 天 / 1 个月 / 3 个月 / 半年 / 1 年 / 全部 |
| **四种模型切换** | 见下 —— 大波段 SENTI-1 / 小波段 SWING（回调底）/ SWING-2（动量拐点）/ SWING-3（均线拐点） |

### 四种模型（页面顶部切换）

| | 大波段 SENTI-1 | 小波段 SWING | 小波段 SWING-2 | 小波段 SWING-3 |
|---|---|---|---|---|
| 抓什么 | **投降底**：恐慌放量、估值投降 | **回调底**：价格位置 + 热度同时到极端 | **动量拐点**：MACD 柱跌到自身极低分位 | **均线拐点**：MA20 斜率跌到极低分位，且当日回升 |
| 代码 | `senti/model.py` | `senti/swing.py` | `senti/swing2.py`（2026-09-23） | `senti/swing3.py`（2026-09-23） |
| 频率 | 每板块每年约 1 次 | 每板块每年约 3.6 次 | 每板块每年约 5.5 次 | 每板块每年约 2.6 次 |
| 判定 | T+20（辅助 T+60） | T+7 | T+7 | T+7 |
| 近 3 年实测 | 89%（但只有 5 次市场级事件，长历史口径 77.8%） | 64.1%（64 次） | 68.7%（99 次） | **85.1%（47 次）** |
| 高置信档 | A 级（估值投降 + 全场共振） | 共振 ≥4：78.3%；S 级 ≥5：81% / 长窗口 87% | 共振 ≥4：89.8%；≥5：89.5% | 共振 ≥4：**88.9%**；≥5：86.7% |

### 小波段信号源四选（SWING 模式下多一排按钮）

三个小波段模型的信号**几乎不重叠**（近 5.7 年 Jaccard：
J(SWING-3, SWING)=0.03、**J(SWING-3, SWING-2)=0.00**、J(SWING, SWING-2)=0.15），
所以默认把它们合并显示 —— 信号更多、胜率还更高：

| 信号源 | 近 3 年 | 近 5.7 年（2021-01 起） |
|---|---|---|
| 回调底 SWING | 64 次 / 64.1% | 90 次 / 61.1% |
| 动量拐点 SWING-2 | 99 次 / 68.7% | 114 次 / 70.2% |
| 均线拐点 SWING-3 | **47 次 / 85.1%** | 72 次 / 76.4% |
| 前两个合并 | 143 次 / 66.4% | 172 次 / 65.1% |
| **三个合并（默认）** | **189 次 / 70.9%** | **242 次 / 68.2%** |

⚠️ **上表是「信号次数」。同一波下跌里三个模型往往隔几天各触发一次，
按同板块 ±4 自然日聚成一件事、只算第一枪之后，独立入场机会数是：**

| 口径 | 事件数 | 事件命中 | Wilson 下界 |
|---|---|---|---|
| 回调底 SWING | 57 | 63.2% | 50.2% |
| 动量拐点 SWING-2 | 84 | 67.9% | 57.3% |
| 均线拐点 SWING-3 | 44 | **84.1%** | **70.6%** |
| **三个合并（默认）** | **136** | **67.6%** | **59.4%** |

并集是**拿命中率换覆盖**（SWING-3 事件级 84.1% 但 3 年只有 44 件事；
并集 136 件事、67.6%，覆盖是它的 3 倍）。页面信号源切换条会同时给出两个数。
详见 `DELIVERY.md` 第 14.5 节。

再往上一层还有**市场级**（跨板块 ±5 自然日算一件事，只算第一枪）——
它回答「这套系统一年动手几次」：

| 口径 | 市场级件数 | 年化 | 命中 |
|---|---|---|---|
| 三模型合并 | 34 | 11.3 次 | 50.0% |
| SENTI-1 底部 | **6** | 2.0 次 | **83.3%** |

⚠️ 市场级「第一枪」口径对信号更密的模型天然不利，**不用于模型排名**。
另外市场级事件里**簇跨度 ≥8 天（连续两三周阴跌）**的那一批，长历史命中率只有
19~36%（跨度 ≤7 天的是 68~77%）—— 这个结构很稳，但**在第一枪时不可知**，
所以只能当风险提示，不能当过滤器。详见 `DELIVERY.md` 第 15 节。

基线 48.6% / 47.5%。合并视图画三条曲线，
▲＝回调底信号、◆＝动量拐点信号、●＝均线拐点信号。
加入 SWING-3 后，**信号 +32%、命中 +4.5pp**，两个维度同时上升。

SENTI-1 与 SWING 的逻辑一行未改，SWING-2 / SWING-3 都是独立模型。

### 它做不到的（很重要）

- **不是高频工具**：每板块每年约 **0.95 次**信号，平均 10~14 个月一次。这是大波段模型。
- **没有顶部信号**：原「首破 100」顶部信号实测 2/9 = 22.2%，随机基线 40.1%，
  优势 −17.9pp，**p = 0.93**（95% 置信区间 [6.3%, 54.7%] 整个跨过基线）；
  长历史口径同样不成立（T+60 下跌 15/29 = 51.7%，基线 47.5%，p = 0.39）。
  唯一能救它的「融资余额分位 ≥70」近 3 年一次都没触发过。
  → 已于 2026-09-22 整体移除。分值 >100 仍照画，但只是过热读数，**不是卖出信号**。
- **命中率请按 78% 理解，不要按 89.5%**：近 3 年的 17 次信号高度重合，
  实际上只对应 **5 次市场级恐慌事件**。放到 13 年长历史是 18 个事件赢 14 个
  （**77.8%**，基线 49.5%，**p=0.014**）—— 这才是最诚实的估计。详见 `DELIVERY.md` 6.7。

## 3. 页面怎么用

页面只有三块：**板块切换 → 左侧当前分值卡片 → 右侧折线图**。

- **左侧卡片**：当前分值、情绪状态、较 5 日前变化、指数点位，底部一行「最近信号」。
- **折线图**：
  - 右上角切换时间范围（以数据最后一天为基准按自然日回溯）
  - 蓝线 = 情绪分值（左轴），灰线 = 指数收盘（右轴，可关）
  - 虚线：0（底部线）、100（顶底线）、入场阈值线
  - 小波段「合并」视图下同时画三条曲线：**SWING 实线（蓝）/ SWING-2 虚线（紫）/
    SWING-3 点线（橙）**，三条都是 0~100 同刻度，可直接比高低
  - **信号点**：一律是「低点买入」信号，画在各自模型的曲线下方
    （顶部信号已移除，不再有方向之分）；
    **A 级 = 实心 + 光环，B 级 = 实心，C 级 = 空心**。
    合并视图里形状区分来源：**▲ 回调底、◆ 动量拐点、● 均线拐点**。
    鼠标悬停可看等级释义与 T+7 涨跌
  - 图上画的就是**原始分值**，与左侧卡片同一个数（已移除「20日平滑」选项：
    平滑后的值与卡片会对不上，容易误读）
  - 图下方一行「**等级有什么用**」说明 A/B/C 的作用
- 卡片底部的**「最近信号」**是信号表移除后唯一的历史回溯入口。

> 原来的「模型说明 / 实测边界」段落已按需求从页面移除，内容都在本文件和 `DELIVERY.md` 里。

### 等级 A/B/C 是干什么的

**等级不决定「出不出信号」，它回答的是「这次信号有几个独立证据支持」，只用来定仓位。**

| 等级 | 含义 | 怎么用 |
|---|---|---|
| **A** | 两个确认层都成立：估值已投降 **＋** 多板块共振 | 证据最足，可正常仓位甚至偏重 |
| **B** | 只成立其中一个 | 常规仓位 |
| **C** | 两个都没成立 | 置信度回落到全样本平均，建议减半或观望 |

两个确认层：
- **估值投降** = 破净股占比处于近一年高分位（**市场级**，管「时机」）
- **全场共振** = 同一天还有别的板块也跌到 ≤0（**横截面**，管「选谁」）

近 3 年分布：A 级 3 个（3/3 命中）、B 级 16 个（14/16）、C 级 0 个。
（等级只用于底部信号；顶部信号已移除。）

## 4. 模型概览（详见 `DELIVERY.md` 第 2 节）

单一模型 SENTI-1，6 板块共用同一套公式：

```
score = 0.5·L（广度情绪） + 0.5·T（价格过热） − 25·cf_b（恐慌放量确认）
```

- **L 广度情绪**（50%）：成分股站上 MA20/MA60 比例、5 日上涨占比、60 日净新高、
  涨跌停净占比、RSI、乖离率、20 日收益
- **T 价格过热**（50%）：乖离率、20 日收益、RSI、成交额分位
- **因果锚**：所有因子用「截至**昨日**的 750 日分位」做刻度锚点，
  避免用未来数据给历史定刻度（这是本项目修掉的最严重的 bug）

### 入场规则

> **昨日分值 ≤ 0 且今日分值高于昨日 → 今日收盘买入**，买入后 20 个交易日内不再重复入场。

实况：触发时**昨日分值中位数是 −11.6**（最深 −18.4），今日回升后当日分值中位 6.3。
所以不是「跌到 0 附近」就买，而是**昨天已经砸到 −11.6 左右、今天开始回升**才买。
阈值 0 就是需求原话「低于 0 是底部」，扫描过 −15 ~ +25，**0 附近是平台，越严并不越好**。

### 事件来了怎么买：等权买多个，别押单个

一次恐慌通常会有好几个板块同时触发。**实测建议按等权买下所有触发板块**，
而不是押注「分值最低（最恐慌）」的那一个：

| 买法 | 生产（3 次事件） | 13 年长历史（11 次事件） |
|---|---|---|
| **等权买全部触发板块** | 命中 2/3，均 +10.42%，**最深浮亏 −5.67%** | 命中 6/11，均 +2.35%，**最深 −19.36%** |
| 只买最恐慌的那一个 | 命中 2/3，均 +10.29%，最深 **−15.91%** | 命中 8/11，均 +2.61%，最深 **−25.87%** |

押单个的命中率略高，但**最深回撤明显更差** —— 用一点命中率换更浅的回撤。
（详见 `DELIVERY.md` 6.8）

> 另外试过做一条「全市场分值」（6 板块分值的中位数）来出信号，**已否决**：
> 中位数会把只有部分板块崩的恐慌磨平，近 3 年只剩 3 次信号、还漏掉 2024-01-23 的大底，
> 长历史 6/11 = 54.5%（p=0.40，不显著）。正确的做法是**事件级聚类**
> （±5 交易日内的多个板块信号算一次事件），见 `DELIVERY.md` 6.7。

### 两个确认层 → 置信等级

| 层 | 含义 | 数据 |
|---|---|---|
| 估值投降 | 破净股占比的 250 日分位 ≥ 60 | 市场级，管「时机」 |
| 全场共振 | 信号日还有 ≥2 个板块分值在 ≤0 | 横截面，管「选谁」 |

**A = 两层都满足**，B = 只满足其一，C = 都不满足。

## 5. 实测成绩（摘要，完整版见 `DELIVERY.md` 第 6 节）

| 口径 | 样本 | 结果 | 随机基线 |
|---|---|---|---|
| 近 3 年 · 信号级 | 19 | 17/19 = 89.5% | 40.8% |
| 近 3 年 · **事件级** | **5** | 5/5（下界 56.6%，p=0.041） | 52.8% |
| 13 年长历史 · **事件级** | **18** | **14/18 = 77.8%（p=0.014）** | 49.5% |
| ~~顶部（首破 100）~~ | ~~9~~ | **已移除**：2/9 = 22.2%，p=0.93，与瞎猜无差异 | 40.1% |

**已知边界**：样本量小（近 3 年只有 5 个有效样本）；不要加止损（实测加了更差）；
最深回撤可达 −23.61%；共振层在全市场同日 V 型反转时会误判为「孤立」。
**请务必读 `DELIVERY.md` 第 7 节。**
